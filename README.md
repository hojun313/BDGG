# BDGG (있고 없고)

'있고 없고'는 주어진 단어들이 특정 규칙에 따라 '있는' 그룹과 '없는' 그룹으로 나뉘는 이유를 맞추는 간단한 추리 게임입니다.

## [🎮 게임 플레이하기](https://hojun313.github.io/BDGG/)

## 룰 설명

1.  **출제자**는 마음속으로 기준을 정합니다. (예: 받침이 있는 글자)
2.  출제자는 기준에 따라 '있는 것'과 '없는 것'의 예시를 보여줍니다.
    *   예시) "사과에는 있고, 포도에는 없어. 나무에는 있고, 숲에는 없어."
3.  **참가자**들은 예시를 보고 규칙을 추리하여, "OO에는 있어?"라고 질문하며 규칙을 유추해 나갑니다.
4.  규칙을 알아낸 참가자가 정답을 외치면 게임이 끝납니다.

## 개발

*   **엔진:** Unity
*   **플랫폼:** WebGL
